# Overview

Volume Guard is a browser extension that keeps movies and series at the volume you chose. You set a target level once. When a song or an action scene gets loud, it turns the sound down. When the dialogue gets quiet, it turns it back up. You stop reaching for the volume button.

Everything happens inside your browser. There is no account, no analytics and no network traffic. The audio is measured in memory and never recorded.

> **Status.** Version 0.1.0 works in Chrome and Edge but is not in the Chrome Web Store yet. You can build it from the source code today: see [Getting started](/docs/getting-started).

## Who it is for

- People who watch late at night and do not want to wake the house.
- Anyone with sensitive hearing who hates sudden loud sounds.
- Fans of Bollywood songs and Hollywood action, where the jump between dialogue and the big moments is largest.
- Headphone users, where a blast hurts and a whisper is lost.

## What it does, in one picture

| The soundtrack does this | Volume Guard does this |
| --- | --- |
| A song or a fight scene gets much louder | Pulls the volume down quickly |
| Two people talk quietly | Lifts the volume slowly, up to a limit |
| A sudden bang | A limiter rounds off the peak |
| Silence | Leaves it alone (silence is never boosted) |
